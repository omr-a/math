# VPN خاص فيك: سريع، خفيف، يحمي خصوصيتك ويحجب الإعلانات

تشغّله على سيرفر سحابي (VPS) خاص فيك، وتتصل فيه من جوالك ولابتوبك بمسح QR code.

| المكوّن | دوره |
| --- | --- |
| **WireGuard** | أسرع بروتوكول VPN اليوم. يشتغل داخل نواة لينكس، تشفيره حديث (ChaCha20 و Curve25519)، واستهلاكه للبطارية قليل. |
| **Unbound** | سيرفر DNS خاص فيك، بدون سجلات، ويتحقق من DNSSEC. يحجب حوالي 170 ألف دومين إعلانات ومتتبعات ومواقع احتيال وبرمجيات خبيثة، وقوائم الحجب تتحدث تلقائيًا كل يوم. |

استهلاك الذاكرة كله أقل من 100MB، فأرخص سيرفر (512MB رام) يكفيه.

## وش يسوي بالضبط

- **سرعة:** WireGuard شغال داخل النواة (مو برنامج عادي)، وفيه حماية من مشاكل الـ MTU اللي تبطّئ الاتصال على شبكات الجوال، والـ DNS يرد من الكاش ويحدّث الأسماء المشهورة قبل ما تنتهي صلاحيتها.
- **حجب إعلانات** على مستوى الشبكة: يشتغل في كل التطبيقات والمتصفحات على كل أجهزتك، بدون ما تثبت أي شي على الجهاز.
- **خصوصية:**
  - ما فيه أي سجلات: لا للمواقع اللي تزورها، ولا لطلبات الـ DNS.
  - الـ DNS يحل الأسماء بنفسه من السيرفرات الجذرية، فما فيه شركة (مثل Google أو Cloudflare) تشوف كل المواقع اللي تطلبها.
  - كل الترافيك (IPv4 و IPv6) يمشي داخل النفق، فما فيه تسريب.
  - التطبيقات اللي تستخدم DNS ثابت (مثل 8.8.8.8) تنحوّل غصب لـ DNS حقك، فتنحجب إعلاناتها بعد.
  - أجهزتك ما تقدر توصل لبعضها عن طريق الـ VPN.

## المتطلبات

- سيرفر VPS عليه **Ubuntu 22.04 / 24.04** أو **Debian 11 / 12**، ونوعه KVM (أغلب المزودين). خوادم OpenVZ و LXC ما تشتغل.
- 512MB رام و 1 معالج تكفي.
- مزودين معروفين: Hetzner، DigitalOcean، Vultr، Linode، و Oracle Cloud (عنده خطة مجانية). السعر غالبًا 4 إلى 6 دولار بالشهر.
- **للسرعة: اختر موقع السيرفر أقرب ما يمكن لك.** هذا أهم عامل للسرعة.

## التثبيت

**1. ادخل على السيرفر** (المزود يعطيك الـ IP وكلمة المرور أو المفتاح):

```bash
ssh root@IP_السيرفر
```

**2. نزّل المشروع وشغّل التثبيت:**

```bash
apt-get update && apt-get install -y git
git clone -b claude/fast-lightweight-vpn-6tl56l https://github.com/omr-a/math.git vpn
cd vpn
sudo ./install.sh
```

التثبيت ياخذ دقيقة تقريبًا، وفي الآخر يطلع لك **QR code** لأول جهاز (اسمه `phone`).

**3. افتح المنفذ:** إذا مزودك عنده جدار حماية في لوحة التحكم (Firewall أو Security Group)، اسمح بـ **UDP 51820**. (Oracle Cloud و AWS و Google Cloud يحتاجونها دائمًا.)

**4. اتصل من جهازك** (تحت).

### إعدادات اختيارية

تحطها قبل أمر التثبيت، مثلًا: `sudo VPN_PORT=443 VPN_LISTS=pro ./install.sh`

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `VPN_PORT` | `51820` | منفذ UDP. استخدم `443` إذا الشبكة اللي أنت عليها تحجب المنفذ الافتراضي. |
| `VPN_LISTS` | `normal` | قوة الحجب: `light` أو `normal` أو `pro` (تحت التفاصيل)، أو روابط قوائمك الخاصة. |
| `VPN_DNS` | `recursive` | `recursive`: السيرفر يحل الأسماء بنفسه (أعلى خصوصية). `quad9` أو `cloudflare`: يرسل الطلبات لهم مشفرة (DNS-over-TLS). |
| `VPN_MTU` | `1420` | خله `1280` إذا بعض المواقع تعلق على شبكة الجوال. |
| `VPN_ENDPOINT` | يكتشفه تلقائيًا | عنوان السيرفر العام (IP أو دومين). |
| `VPN_IPV6` | يكتشفه تلقائيًا | `yes` أو `no`. |
| `VPN_CLIENT` | `phone` | اسم أول جهاز. |

## الاتصال من أجهزتك

ثبّت تطبيق **WireGuard** الرسمي:

| الجهاز | الطريقة |
| --- | --- |
| **iPhone / iPad** | من App Store ثبّت WireGuard، بعدين ➕ ثم **Create from QR code** وامسح الكود. |
| **Android** | من Google Play ثبّت WireGuard، بعدين ➕ ثم **Scan from QR code**. |
| **Windows / macOS** | من [wireguard.com/install](https://www.wireguard.com/install/) ثبّت البرنامج، بعدين **Import tunnel(s) from file** واختر ملف الجهاز. |

لكل جهاز جديد سوّ له اسم خاص فيه (لا تستخدم نفس الكود على جهازين):

```bash
sudo vpn add laptop
```

لنقل ملف الإعداد للكمبيوتر، شغّل هذا **على كمبيوترك** (مو على السيرفر):

```bash
scp root@IP_السيرفر:/etc/vpn/clients/laptop.conf .
```

## الأوامر

| الأمر | وش يسوي |
| --- | --- |
| `sudo vpn add NAME` | يضيف جهاز ويطلع الـ QR code حقه |
| `sudo vpn remove NAME` | يحذف جهاز (مثلًا لو ضاع جوالك) |
| `sudo vpn list` | الأجهزة، آخر مرة اتصلت، وكمية البيانات |
| `sudo vpn show NAME` | يطلع الـ QR code مرة ثانية |
| `sudo vpn update` | يحدّث قوائم الحجب الحين (تتحدث تلقائيًا كل يوم) |
| `sudo vpn allow DOMAIN` | يسمح بدومين محجوب (لو موقع أو تطبيق خرب) |
| `sudo vpn block DOMAIN` | يحجب دومين ودوميناته الفرعية |
| `sudo vpn unallow DOMAIN` / `unblock DOMAIN` | يلغي السماح أو الحجب |
| `sudo vpn status` | حالة الخدمات وعدد الدومينات المحجوبة |

## حجب الإعلانات

القوائم من [HaGeZi DNS Blocklists](https://github.com/hagezi/dns-blocklists)، وهي من أدق القوائم وأقلها تخريبًا للمواقع:

| المستوى | عدد الدومينات تقريبًا | متى تستخدمه |
| --- | --- | --- |
| `light` | 70 ألف | أقل حجب، ما يخرب شي تقريبًا |
| `normal` (الافتراضي) | 170 ألف | توازن ممتاز للاستخدام اليومي |
| `pro` | 210 ألف | حجب أقوى، أحيانًا تحتاج `vpn allow` لبعض المواقع |

تقدر تغيّر المستوى بعد التثبيت: عدّل `VPN_BLOCKLISTS` في `/etc/vpn/vpn.conf` (تقبل أكثر من رابط، بينها مسافة)، وبعدين شغّل `sudo vpn update`.

**إذا موقع أو تطبيق ما اشتغل** صح، اسمح للدومين حقه:

```bash
sudo vpn allow example.com
```

**حدود حجب الـ DNS (بصراحة):**

- **إعلانات يوتيوب** و**الإعلانات الممولة في إنستقرام وتيك توك** تجي من نفس سيرفرات المحتوى، فما ينفع تنحجب بالـ DNS. للمتصفح، أضف [uBlock Origin](https://ublockorigin.com/).
- لو فعّلت **"Secure DNS"** في المتصفح بمزود معيّن، أو **"Private DNS"** في أندرويد باسم سيرفر، الجهاز بيتجاوز الحجب. خلها على **Off** أو **Automatic**.
- Firefox و **iCloud Private Relay** يتعطل تجاوزهم تلقائيًا وأنت متصل بالـ VPN، عشان يشتغل الحجب.

## الخصوصية والأمان

- **بدون سجلات:** WireGuard ما يسجل شي، وسجلات Unbound مقفلة. الشي الوحيد اللي ينحفظ هو "آخر اتصال" وكمية البيانات اللي تشوفها في `vpn list`، وهذي في الذاكرة بس وتنمسح مع إعادة التشغيل.
- **مفاتيح:** كل جهاز له مفتاح خاص فيه، ومعه مفتاح مشترك إضافي (preshared key) كطبقة حماية زيادة.
- **Kill switch** (يقطع الإنترنت إذا فصل الـ VPN، عشان ما يتسرب شي):
  - **Android:** الإعدادات ← الشبكة ← VPN ← ⚙️ جنب WireGuard ← فعّل **Always-on VPN** و **Block connections without VPN**.
  - **iPhone:** في تطبيق WireGuard افتح النفق وفعّل **On-Demand** عشان يتصل تلقائيًا.
  - **Windows:** مفعّل تلقائيًا.
- **وش يحميك منه:** شبكات الواي فاي العامة (الكافيهات والمطارات)، ومزود الإنترنت حقك، لأنهم ما يشوفون غير اتصال مشفر رايح لسيرفرك.
- **وش ما يسويه:** المواقع تشوف IP سيرفرك بدل IP بيتك. هذا خصوصية، مو إخفاء هوية كامل مثل Tor، لأن السيرفر باسمك.

## السرعة

- **موقع السيرفر** أهم شي: كل ما كان أقرب لك، كل ما كان أسرع.
- إذا بعض المواقع **تعلق أو تفتح نص** على شبكة الجوال، خل MTU يصير `1280`: عدّل سطر `MTU` في إعداد الجهاز، أو خل `VPN_MTU="1280"` في `/etc/vpn/vpn.conf` للأجهزة الجديدة.
- إذا **ما يتصل أبدًا** من شبكة معينة، الشبكة غالبًا تحجب المنفذ. ثبّت من جديد بـ `VPN_PORT=443`.
- WireGuard خفيف على المعالج: سيرفر بمعالج واحد يعطيك مئات الميقابت.

## تحديث السكربتات

```bash
cd vpn && git pull && sudo install -m 755 vpn /usr/local/bin/vpn
```

## الإزالة

```bash
sudo ./uninstall.sh
```

يحذف الـ VPN وكل الأجهزة والإعدادات (البرامج نفسها تبقى، والأمر يقول لك كيف تحذفها).

## تنبيه

قوانين استخدام الـ VPN تختلف من دولة لدولة. تأكد من القوانين عندك واستخدمه بشكل نظامي.

## للمطورين

| الملف | الوصف |
| --- | --- |
| `install.sh` | يثبت الحزم، يكتشف إعدادات الشبكة، ويكتب إعدادات WireGuard و Unbound و systemd. |
| `vpn` | أمر الإدارة (يتثبت في `/usr/local/bin/vpn`). wg-quick يستدعي `vpn firewall up/down` لقواعد الجدار الناري. |
| `uninstall.sh` | يحذف كل شي سواه التثبيت. |
| `tests/run.sh` | اختبارات تشتغل بدون شبكة داخل مجلد مؤقت. |

مكان الملفات على السيرفر:

| المسار | المحتوى |
| --- | --- |
| `/etc/vpn/vpn.conf` | الإعدادات |
| `/etc/vpn/clients/` | ملفات إعداد الأجهزة |
| `/etc/vpn/allowlist.txt`, `/etc/vpn/blocklist.txt` | قوائم السماح والحجب الخاصة فيك |
| `/etc/wireguard/wg0.conf` | إعداد WireGuard للسيرفر |
| `/etc/unbound/unbound.conf.d/vpn*.conf` | إعداد الـ DNS وقائمة الحجب المولّدة |

تشغيل الاختبارات (تحتاج `wireguard-tools` و `unbound` و `qrencode`):

```bash
shellcheck -x vpn install.sh uninstall.sh tests/run.sh
sudo tests/run.sh
```
